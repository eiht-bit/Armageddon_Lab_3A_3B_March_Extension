APPI compliance and data residency justification. 
This multi-regional architecture is designed to comply with Japan's act on the protection of personal information by enforcing the strict separation between data storage and compute. All personal identifiable INF and protected health info is stored exclusively in the Tokyo region on its database it's hosted in private subnets and has no access to the public the Sao Paulo region operates It's just a compute node it runs the same app code but it has no database or secrets or any patient info one Sao Paulo needs to read read the data It gains access to the transit gateway to make sure data never physically leaves Japan.
