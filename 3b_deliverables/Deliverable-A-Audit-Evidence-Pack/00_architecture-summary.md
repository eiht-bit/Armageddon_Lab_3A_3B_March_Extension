This architecture consists a multi-region AWS deployment between Tokyo and Sao Paulo with a database residing in Tokyo. The architecture is designed to follow Japan's laws to protect personal information while allowing access from Sao Paulo. The Tokyo region has a VPC with private and public subnets across two availability zones with an EC2 and database in the private subnet. The Application Load Balancer only accepts traffic from cloud which has a custom domain. There's a certificate for the domain with a hosted zone with alias records pointing to cloudfront. The secret manager stores the credentials for the RDS the parameter store handles the end point ports and the database name. There's also a Transit gateway for peering into Sao Paulo. Sao Paulo infrastructure also has a VPC with public and private sub and an EC2 with the same web app but Sao Paulo does not have a database but has access to Tokyo's database. The database as a security group which allows inbound 3306 traffic from Sao Paulo. Both regions have a transit gateway for paring into each other.
